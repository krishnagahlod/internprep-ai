# TasteSkill v2 — Anti-Slop Design Harness

## Tuning Dials (Scale 1–10)
- **DESIGN_VARIANCE: 4/10** — Strict, consistent, high-discipline structural grids without arbitrary chaotic shifts.
- **MOTION_INTENSITY: 5/10** — Fast, subtle 150ms state-feedback transitions. No disorienting page-wide flying elements.
- **VISUAL_DENSITY: 7/10** — High technical information density (clean cards, structured tables, mono scorecards, zero puffy empty space).

## Banned AI Anti-Patterns
1. **NO em-dashes ("—")** in marketing copy. Use concise, active sentences.
2. **NO decorative emoji badges (⚡, ✨, 🚀, 💡, 🔥)** or `Sparkles` icons used as generic AI indicators.
3. **NO pastel rainbow blur halos** or multi-color gradient text.
4. **NO bubbly `rounded-3xl` corners** (24px–32px). Standardize on `rounded-lg` (8px) and `rounded-xl` (12px).
5. **NO generic 3-card feature columns** with stock illustrations. Use structured 2-column technical deep dives.
6. **NO ungrounded hallucinated claims**. Strictly showcase actual features and working tools.
